## 设计变量

变量入口为 `web/design-tokens.css`，在原样式后加载。物理弹簧定义在 `web/motion.ts`。

| 变量 | 浅色 | 深色 |
| --- | --- | --- |
| 展墙背景 | `#FAF8F5` | `#1E1C18` |
| 纸张表面 | `#FDFBF7` | `#28251F` |
| 下沉表面 | `#F0ECE5` | `#302C25` |
| 主文字 | `#1A1814` | `#D9D1C4` |
| 次文字 | `#39342C` | `#C5BBAB` |
| 辅助文字 | `#6E675D` | `#A69D8E` |
| 微弱文字 | `#A49B8F` | `#827A6E` |
| 唯一色彩强调 | 鼠尾草 `#6F7D66` | `#A0AD91` |
| 运行 / 警告 / 断开 / 未启动 | `#7B8C75` / `#B09668` / `#AE7E74` / `#B8B0A4` | `#98A58C` / `#B9A078` / `#BA9286` / `#726A5D` |
| 细分隔 | 墨色 6%，较强 8.5% | 暖浅墨色 5.5%，较强 8.5% |

色彩强调用于选中、主控与键盘焦点。主按钮使用暖墨色或深色下的暖纸色。状态色只承担状态含义，图标共用单色线条。

- 正文：本地 Manrope / Noto Sans SC 可变字体，常用 400 / 500 / 600；禁止合成字重。数字启用 `tabular-nums`。
- 衬线：页面标题和空状态使用本地 Vela Serif（思源宋体子集）；Logo 保留 Playfair Display。其他区域使用黑体。
- 字号变量：12 / 13 / 14 / 16 / 24px。页面标题行高 32px，正文控件采用 16 / 20 / 24px 行高。旧管理页仍有局部硬编码字号，尚未全部归一。
- 间距：4 / 8 / 12 / 16 / 24 / 32px；工作台卡片间距 16px。
- 圆角：外卡片 12px、按钮与输入 8px；嵌套浮层按距离缩小。
- 纸张阴影：贴近层 `0 1px 1px rgba(43,35,23,.025)`，扩散层 `0 8px 24px rgba(43,35,23,.03)`。深色独立调整至 `.08` / `.065`。
- 纹理：背景 2.4% 细噪点；无大面积毛玻璃。
- 动效：hover 100ms、退出 180ms、小控件 220ms、布局 420ms、卡片错开 24ms。侧栏宽度 320ms。CSS `linear(...)` 是阻尼弹簧轨迹的分段采样，不是匀速曲线。

| 弹簧 | 质量 | 刚度 | 阻尼 |
| --- | --- | --- | --- |
| 转环 | 1.15 | 420 | 37.5 |
| 布局 | 1 | 420 | 35 |
| 控件 | 0.7 | 650 | 34 |

系统减少动态效果时取消视差、巡航、错开与过渡。侧栏同一套 DOM 连续收展，途中反向从当前画面继续。

## 本轮已实现

- 暖纸色全局主题、独立深色、真实中文字重、本地字体及许可、单色线性图标、低饱和状态、极淡纸张阴影。
- 环形画布：单卡片取模、双向无限转动、惯性吸附、48px 渐隐、分组同步、搜索定位、全览、聚焦、框选 / Ctrl / Shift 多选、批量操作、显式群控。
- 16:10 画面与 32px 信息底栏；名称与状态不再常驻覆盖网页；hover 操作胶囊；加载骨架与局部错误 / 重连。
- 68px 图标侧栏、320ms 收展和快速反向、分组菜单 hover、导入说明。整个产品移除账户体系，设置只保留通用和高级；发布版本号在品牌悬停提示中，dev 保留角标。
- Ctrl+K 工作区索引：环境、分组、公开代理地址、脚本、页面与外观命令。打开脚本只定位编辑页。
- 采帧分级与移动冻结，迟到帧丢弃；聚焦仅缩放画面，不更改真实浏览器尺寸或指纹。屏外跟随可接收明确开启的群控输入。
- 配置表格、设置、代理和扩展页面继承暖色变量并减少面板边框和阴影。
- 本地筛选保存、按条件交集筛选、环境详情抽屉；模板、实时配置摘要与批量命名创建。模板不携带身份 seed、Cookie、网站账号或代理凭据；批量创建支持停止、续建、只重试明确失败项，并保护结果不明的请求。
