# Vela Browser 今夜实施计划

2026-11-10 · 台北时间。按用户最终的“画廊”要求更新。设计变量先于组件，详见 `2026-11-10-gallery-design.md` 与 `web/design-tokens.css`。

## 目标与视觉

工作台是展墙，独立浏览器画面是展品。暖纸色背景、暖墨文字、低饱和状态、单色线性图标、极淡双层纸张阴影。正文使用本地 Manrope / Noto Sans SC 真实字重；衬线只用于 Logo、页面标题和空状态。

“砌砖”仅表示上下错缝的排布方式。最终卡片为 12px 圆角、16px 间距、16:10 画面和 32px 信息底栏。名称、编号、状态、代理信息与内核放在底栏，取代早期常驻水印。

## 环形画布

- 用同一个 offset 控制滚轮、拖动、左右按钮、键盘、巡航和定位。各行位置取模，一环境一张 DOM 卡片，无头尾、无克隆节点。
- 自动选择一至三行。环周长必须足够让卡片在两边完全屏外时换圈；不足时减少行数，仍不满足则普通网格。12 环境在 1440×1000 下通常两行，不强塞三行制造缺口。
- 三行时中行增大 9%，上下行速度 0.85，中行 1.0。以中行为吸附参照，松手按速度预测落点；物理弹簧有重量感及微回弹。
- 左右 48px 渐隐；底部状态点指示器支持拖转、点击定位与预览，代替横向滚动条。正反向连续跨圈。
- 巡航默认关闭，由用户显式启动。系统减少动态效果时禁用巡航和视差。
- 顶部与侧栏共用分组筛选；切换采用共享元素过渡，并保护快速连续切换的最后一次状态。

## 画面与操作

- 预览按宽度等比缩放；聚焦用 contain 完整显示真实画面，输入坐标计入留白。小窗和聚焦均不更改实际浏览器视口、DPR、屏幕或指纹配置。
- 单击选中并定位，双击 / Enter 聚焦；Esc 或外侧空白归位。原卡片连续变形，其余画面淡化。
- hover 胶囊提供置前、标签、主控、聚焦和关闭。标签栏独立显隐，查看、切换、新建、关闭均操作真实浏览器。
- 搜索、全览网格、Ctrl / Shift 点选与框选；批量启动、停止、移组和换代理，沿用现有权限和生命周期限制。
- 群控仅在明确设置主控后开启；状态条显示主控与跟随数，一键停止。屏外跟随不采画面但可接收同步输入；坐标按各自真实尺寸归一化。
- 加载骨架、断开降饱和与局部重连、未启动占位、脚本进度、键盘可见焦点及弹窗焦点限制。

## 底层隔离与性能

每环境保留独立进程、数据目录、Cookie、存储、代理和指纹。显示连接绑定环境、启动代次与标签，拒绝过期帧和输入。离开工作台释放显示连接，不关闭浏览器。

画面使用 img 换帧，屏外暂停、渐隐区约 0.5fps、完整可见约 3fps、hover / 聚焦目标最高约 20fps，实际受浏览器采集成本限制。转动时服务端停采集并丢弃在途帧，客户端再拦截迟到帧，停稳后恢复。

Chromium 通过现有 CDP；Firefox 通过独立 owner / Playwright 链路。基础 WebKit 接入和指纹能力是另外的验收范围，不能用两个工作台适配器的结果推断三内核指纹完整。

## 侧栏与全局框架

- 248px（较窄窗口 200px）至 68px 图标栏，320ms 弹簧轨迹；品牌、文字、图标和主内容同步过渡，支持途中反向。760px 以下强制图标栏。
- 分组操作仅 hover / focus 出现；新建分组、导入说明、dev 角标及状态点统一。
- Ctrl+K 工作区索引搜索环境、分组、公开代理地址、脚本和命令。脚本打开编辑页，不因搜索直接执行。
- 明暗主题独立调色；管理页去大外框和玻璃面板，字号与控件逐步对齐变量。
