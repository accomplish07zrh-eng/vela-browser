# Security Policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability.

Report it privately through [GitHub security advisories](https://github.com/accomplish07zrh-eng/vela-browser/security/advisories/new). Include the affected version, reproduction steps, and impact.

Never send real cookies, passwords, proxy credentials, TOTP seeds, profile exports, private keys, or unredacted diagnostics.

## Supported versions

Vela Browser is currently in beta. Security fixes apply to the newest published release.

## Scope

Security reports may cover the desktop client, local API, installer, update notification, or interactions with Vela Cloud. The CloakBrowser runtime has its own security and reporting process.
